# TETRIS BLITZ — 设计简报

## 设计简报 (Design Brief)

- **玩家承诺**：在倒计时的高压下，用"带道具的方块"快速消行刷分——每一块落下的方块都可能藏着翻盘道具。
- **目标感受**：任天堂《俄罗斯方块》的清晰读盘 + 卡普空《宝石方块》(Puzzle Fighter) 的华丽连锁爽感，街机限时挑战的紧张节奏。
- **主要动词**：摆放方块（左右移动 / 旋转 / 软降 / 硬降）。
- **次要动词**：消行得分、触发方块上附带的道具、规划堆叠、争取连消 (combo)。
- **每 5–30 秒重复**：倒计时内落下 1–3 块，决策是否优先消掉"带道具的方块"，消行回时间、得分、升等级。
- **1–5 分钟变化**：等级提升使下落加速（LV1→LV4）；倒计时逼近带来警告压力；道具出现率随时间提升；得分翻倍窗口制造冲刺机会。
- **失败方式**：时间耗尽 (TIME UP) 或方块堆到顶 (TOPPED OUT)。失败画面明确显示原因，一键重开。
- **奖励**：消行得分（1/2/3/4 行 100/300/500/800 × 等级）、连消加成、道具效果（+8 秒、减速、清底行、双倍分、+300 分）。
- **风险**：时间耗尽；为追道具块而破坏堆叠结构；堆叠过高逼近死亡线。
- **高手不同之处**：预留竖井等待道具块、在双倍分窗口内打连消、管理减速与时间道具的使用时机。
- **信息传达**：计时器最后 10 秒变红+滴答声；道具块有发光宝石标记+图标；幽灵投影显示落点；堆叠过高时 HUD 红色脉冲警告。
- **非目标（本切片不做）**：对战/联机、道具库养成、无尽模式以外的内容。

## 核心循环契约 (Core Loop Contract)

> 玩家 **[移动/旋转并锁定方块]** 达成 **[消除整行获得分数与额外时间]**，同时 **[下落不断加速且总时间有限]** 制造风险；成功给予 **[分数 / 加时 / 道具效果]**，失败造成 **[Game Over + 一键重开]**。

逐条证明（代码落实）：

| 契约子句 | 代码证明 |
| --- | --- |
| 动词→真实输入 | 键盘（←→ 移动 / Z·↑ 顺时针 / X 逆时针 / ↓ 软降 / 空格硬降 / P 暂停）+ 触控按钮（◀ ▶ ⟳ ↺ ▼ ⏬ ⏸）均发射同一组 intent |
| 目标可见 | HUD 显示分数/等级/剩余时间/下一个方块；消行有逐行闪烁动画与粒子爆发 |
| 压力首分钟即存在 | 初始 120 秒倒计时，LV 每 30 秒加速一次（0.9s→0.35s/格） |
| 奖励改变状态 | 道具真实改变状态：+8s 加时、SLOW 12s 降速、BOMB 清底部 2 行、2X 12s 分数翻倍、BONUS +300 分 |
| 失败可理解 | Game Over 面板显示失败原因（时间耗尽/堆满）与最终分数、最高分 |
| 重开够快 | 失败面板"再来一局"按钮一键 reset（< 1s 进入新局） |

## 关卡 / 难度曲线计划 (Level Plan)

- **空间格式**：10 宽 × 22 高（顶部 2 行隐藏区）的标准井式棋盘；透视相机自动适配横竖屏，棋盘始终完整可见。
- **单局结构**：限时 120 秒冲刺；消 1 行 +4 秒（多行消按行数累加，如 3 行 +12 秒）。
- **等级**：LV1(0s) 0.9s/格 → LV2(30s) 0.7s → LV3(60s) 0.5s → LV4(90s) 0.35s；软降 ×20、硬降瞬落。
- **道具曲线**：每块 18% 概率附带道具（每块至多 1 个，图标在随机格上）；60 秒后提升至 26%。道具在方块锁定时激活。5 种：TIME+8 / SLOW(12s, 重力×0.55) / BOMB(清底 2 行) / 2X(12s 分数×2) / BONUS(+300)。
- **连消**：连续"消行锁定"提升连消倍率（×1 → ×1.5 → ×2 → ×2.5 → 封顶 ×3），断连重置。
- **恢复节奏**：BOMB 与 SLOW 是压力释放道具；每局 120s 内预期遇到 5–8 个道具块，形成"积压→爆发"节奏。
- **电报**：道具块带发光宝石+图标徽记；幽灵投影；最后 10 秒倒计时红闪+滴答；堆叠超过 15 行时 HUD 红色脉冲。
- **模块化**：颜色、重力表、道具表、分数表全部为具名常量，lil-gui 可实时调参。

## 美术方向 (Art Direction)

任天堂街机式高饱和糖果色方块 + 卡普空式光泽宝石质感：斜面倒角块体、顶部高光面、深色街机机柜背板、两侧霓虹灯带、消行爆发粒子。UI 用粗体街机风排版（CSS 层叠文字阴影）。全程序化生成，无外部素材依赖。音效为 Web Audio 合成 8-bit 风 SFX + 循环 chiptune 背景乐，可静音。
